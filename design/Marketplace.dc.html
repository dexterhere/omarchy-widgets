Make your own, at your level

1. Tweak

Change size, accent and fields on any installed widget. The original stays untouched.

2. Design visually

Place text, bars and graphs on a canvas and bind them to provider fields. Exports a spec widget with no code.

3. Write code

Scaffold a QML plugin with the kit and a manifest, then save to reload it.

Your data stays yours

Encrypted vault

Tokens and saved data are encrypted on disk. Network data lives in memory only.

Per-widget grants

A widget sees only the data you approved, and only from hosts its provider is allowed to call.

Audit log

Every read is written down, so you can see which widget asked for what.

Contribute a widget

  1. Start from the template and describe your widget in widget.json.
  2. Open a pull request. CI validates the manifest, lints the permissions and renders a preview.
  3. A maintainer reviews it. The approved commit is what the marketplace installs.
